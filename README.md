# Hidden Object 90s

Первый браузерный прототип: одна тестовая комната, десять предметов, поиск нажатием, список, завершение и перезапуск. TypeScript + Vite + Phaser 3, без backend и дополнительных фреймворков.

Основная целевая платформа — Android. Браузерная версия нужна для быстрой разработки и проверки механик; iOS сейчас не входит в обязательный объём. Упаковка в APK, Android SDK, публикация в Google Play и смена стека не входят в текущую задачу.

## Запуск в Windows PowerShell

Нужны Node.js 22.14 или новее и npm.

```powershell
cd D:\Projects\hidden-object-90s
npm install
npm run dev
```

Откройте адрес, указанный Vite в терминале. Для проверки с телефона в той же локальной сети используйте сетевой адрес из вывода Vite; доступ может зависеть от настроек брандмауэра Windows. Остановить сервер: `Ctrl+C`.

```powershell
npm run build
npm run preview
```

Сборка сначала проверяет типы TypeScript, затем создаёт `dist/`. `preview` позволяет проверить результат сборки в браузере. Для воспроизводимой установки по lock-файлу используйте `npm ci`.

## Игра

Держите экран горизонтально. Нажимайте на изображения предметов в комнате: найденный предмет отмечается в списке, повторное нажатие не засчитывается. После десятой находки появляется сообщение о завершении. «Начать заново» сбрасывает поиск в любой момент. На низком экране боковая панель прокручивается отдельно от сцены. При вертикальном положении появляется инструкция повернуть устройство; прогресс сохраняется до перезапуска или перезагрузки страницы.

## Структура и данные

- `src/data.ts` — библиотека предметов и данные тестового уровня.
- `src/main.ts` — загрузка ресурсов, сцена, обработка нажатий и состояние поиска.
- `src/style.css`, `index.html` — список и управление вне игровой области, адаптация и сообщение об ориентации.
- `public/assets/room.svg` — отдельный фон.
- `public/assets/items/` — десять отдельных изображений с прозрачным фоном.
- `docs/` — требования и архитектура; `AGENTS.md` — правила работы.

Чтобы заменить временную графику, замените соответствующий файл либо измените путь в `library` или `level.background` в `src/data.ts`. Допустимы локальные SVG и PNG с прозрачным фоном для предметов. Путь задаётся относительно `public/`. Сохраняйте размеры ресурса или скорректируйте масштаб размещения.

Чтобы добавить размещение, добавьте запись в `level.items`: уникальный `id`, существующий `itemId` из `library`, `x`, `y`, положительный `scale` и `rotation`. Для нового предмета сначала добавьте определение с названием и путём в библиотеку. Список и условие завершения автоматически используют все размещения уровня.

Координаты отсчитываются от левого верхнего угла сцены: X вправо, Y вниз; позиция предмета задаёт центр изображения, поворот — в градусах по часовой стрелке. Масштаб применяется к исходному размеру изображения. Базовые размеры тестового фона — 1000 × 700: это координатная сетка данного ресурса, а не требование к соотношению сторон устройства. Phaser FIT вписывает сцену целиком в доступную область с сохранением пропорций и свободными полями. Фон и предметы масштабируются вместе; прозрачные пиксели предметов не принимают нажатия.

Для другого уровня подготовьте фон и объект `Level` с нужными размерами и размещениями, затем выберите его как экспорт `level` в `src/data.ts`. Игровую сцену менять не нужно. Интерфейс выбора уровней не входит в прототип.

## Ручная проверка

1. Открыть игру на широком и более узком горизонтальных экранах: видны фон и десять предметов, список доступен, сцена не искажена и не перекрыта панелью.
2. Нажать на каждый предмет: он отмечается в списке и плавно исчезает за 250 мс. С начала анимации он больше не перехватывает нажатия; повторное нажатие не увеличивает счёт. Нажатие на фон или прозрачный край изображения не засчитывается.
3. Найти девять предметов: завершения ещё нет. Найти десятый: появляется «Все предметы найдены!».
4. Перезапустить как незавершённый, так и завершённый уровень, а также во время исчезновения: счёт становится нулевым, все отметки очищаются, все десять предметов вновь видимы и доступны для поиска.
5. Изменить размер окна и повторить поиск: координаты и области нажатия совпадают с изображениями.
6. Повернуть экран в вертикальное положение и обратно: инструкция появляется и исчезает, текущий прогресс сохранён.

## Ограничения

Графика временная, создана в проекте как SVG-заглушки; художественная полировка не выполнялась. Нет сохранения прогресса между перезагрузками, нативной блокировки ориентации и дополнительных игровых механик. Полная клавиатурная доступность игрового canvas пока не реализована; поиск рассчитан на мышь или касание. На небольших экранах список может требовать прокрутки.
