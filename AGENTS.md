# Правила работы над Hidden Object 90s

## Общение и требования

- Общаться с пользователем на русском языке.
- Считать [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) и [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) источником согласованных требований, учитывая явно обозначенный предварительный статус решений.
- Не представлять предварительные решения как окончательно утверждённые. Стек TypeScript + Vite + Phaser 3 пока предварительный.
- Если требования противоречат друг другу, сначала задать пользователю вопрос и не выполнять зависящие от ответа изменения до уточнения.
- Перед существенными изменениями объяснять предлагаемый подход.

## Объём и архитектура

- Не усложнять архитектуру без необходимости; стремиться к простой реализации и минимуму зависимостей.
- Не добавлять функции, которых нет в утверждённой документации.
- Отделять данные уровней от игрового кода и использовать переиспользуемую библиотеку предметов.
- Обеспечивать добавление новых уровней в рамках согласованных механик через данные и ресурсы без изменения игрового движка.
- Не создавать сложный редактор уровней на этапе MVP.
- Не добавлять самостоятельно сюжет, персонажей, систему энергии, таймер, магазин, аккаунты или другие дополнительные механики.
- Не реализовывать монетизацию и подсказки в MVP. Необязательная реклама за подсказки рассматривается только как перспективное направление.

## Текущий этап

Сейчас разрешена только работа над документацией. Не писать код игры, не устанавливать зависимости и не создавать конфигурацию сборки до отдельного поручения пользователя перейти к реализации.

## Сохранность и проверка

- Не удалять существующие данные без разрешения пользователя.
- После изменений проверять результат в объёме, соответствующем задаче.
- При изменении документации проверять внутреннюю согласованность, ссылки, границы MVP и статус предварительных решений.
- При будущих изменениях игры проверять затронутое поведение и соответствие документированным требованиям.
- Не выполнять git commit и git push без отдельного указания пользователя.
